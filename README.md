# Biswas Exports Website

Production-ready corporate frontend for Biswas Exports, a merchant export company based in Asansol, West Bengal, India.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
- React Hook Form
- Zod
- ESLint
- Prettier

## Setup

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL` when testing canonical URLs or social metadata against a deployment URL.

## Quality Checks

```bash
npm run typecheck
npm run lint
npm run build
```
